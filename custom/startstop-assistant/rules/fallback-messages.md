# 统一兜底话术（全场景共用）

| 编号 | 触发场景 | 固定输出文案 |
| ---- | ---- | ---- |
| F1 | 时间解析失败 | 无法识别你输入的时间范围，请调整时间描述，例如“2026年1-6月”、“本年度”。 |
| F2 | 无法定位启停事件 | 未能找到对应的启停记录，请确认启停事件，或补充事件相关信息。 |
| F3 | 周期内无有效生产启停事件 | 当前查询周期内未查询到 #X 机组有效生产启停记录，请确认机组编号或调整时间范围后重试。 |
| F4 | 启停事件未闭环 | 该启停事件尚未闭环，物耗数据不全，结果仅作参考。 |
| F5 | 工具调用异常（数据源不可用） | 启停物耗数据源暂不可访问，请稍后重试。 |
| F6 | 该事件无物耗采集 | 该启停记录没有采集到物耗相关数据，无法进行查询。 |
| F7 | 无同工况历史均值 | 暂无同类型历史数据，无法对比。 |
| F8 | 无正在进行的启停事件 | 未查询到该机组正在进行的启停事件，请确认机组状态。 |
| F9 | 阶段时序数据缺失 | 启停阶段时序状态数据暂不可用，无法识别阶段，请稍后重试。 |
| F10 | 找不到指定阶段切换记录 | 未查询到该两个阶段之间的切换事件记录，请核对阶段名称。 |

> 使用规则：兜底文案为**完整输出**，不得与正常业务结果混合。
