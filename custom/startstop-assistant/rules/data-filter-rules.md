# 数据过滤与业务口径（全场景共用）

## 1. 事件类型过滤（强制）
以下事件**一律剔除**，不参与任何统计、展示与下钻：
- 调试启停
- 试验冲转
- 检修试转
- 程控联动试验
- 大修后空转试验

## 2. 脏数据剔除
- 启停开始时间 / 结束时间为空；
- 事件动作类型为空；
- 重复补录（首尾时间完全相同的重复记录，只保留一条）。

## 3. 未闭环事件处理
| 场景 | 处理方式 |
| ---- | ---- |
| 单次物耗查询 | 保留，但标注“本次启动尚未闭环，物耗数据不完整，仅供临时参考” |
| 次数统计 | 未闭环停机不计入停机次数；未闭环启动不计入启动次数 |
| 停机时长 | 进行中停机单独标记，不参与占比分母 |
| 阶段识别 | 正常识别，标注“中间快照，结果以闭环后为准” |

## 4. 数据集质量元信息（内部判断，按需对外提示）
- 原始记录数 → 过滤丢弃数 → 有效事件数；
- 事件闭环率 = 闭环事件数 / 有效生产事件数；
- 闭环率 < 80% 时，必须在输出中追加数据质量提示。

## 5. 统计口径
- 统计周期：默认自然年，支持用户自定义 `[startTime, endTime]`；
- 启停耗时：点火至并网（启动），解列至停机结束（停机）；
- 物耗归属：以事件开始时刻归属统计周期；
- 冷/温/热态分类：依据机组缸温 / 停机冷却时间标签判定。
