# 场景A：启停物耗查询

## 触发条件
- 关键词命中任一物耗指标：水、煤、油、厂用电、物耗、油耗、耗油、消耗量、阶段耗油；
- 或含物耗对比 / 差异率 / 占比语义。

## 分支路由（单轮只进一个分支）

| 分支 | 触发语义 | 优先级 |
| ---- | ---- | ---- |
| A1 单次启停总物耗 | 本次/这次 启动/停机 消耗了多少 | 2 |
| A2 历史指定事件油耗明细 | 历史上这次XX启动的油耗 / 哪个阶段最耗油 | 3 |
| A3 两次启停事件对比 | 把这两次 对比 / 差异率 | 1 |
| A4 单次启动阶段燃油拆解 | 本次启动哪个阶段最耗油 | 2 |

> 冲突时按优先级取最高，不混合。

## A1：单次启停总物耗查询
**问句示例**
- 本次机组启动消耗了多少水、煤、油和厂用电？
- 本次停机消耗了多少水、煤、油和厂用电？

**处理逻辑**
1. 从对话上下文识别目标「本次启动」事件，提取机组标识、启停事件ID；若上下文无有效事件ID，返回F2兜底提示。
2. 先调用`startStopRecord`工具获取最近10次的启停记录根据问答取相关启动/停止 参数为 `nodeId` 前置skill的id取值 筛选出来第一条数据
2. 调用工具 `getStartStopTotalMaterial`，参数`resultId`为筛选出来数据的 result_id 获取该次启动总物耗、各阶段分项物耗、同工况启动历史均值数据。
3. 输出组装：
    - 输出水、煤、油、厂用电四项**总消耗量**；
    - 输出本次启动、停机各关键阶段的分项物耗明细；
    - 数据源存在历史均值时 需要对比本次和历史启动、停机各关键阶段的各分项物耗明细记录
    - 针对本次物料数据分析总结出结论
4. 边界校验：若启停事件状态为未闭环，增加提示文本：`本次启动尚未闭环，物耗数据不完整，仅供临时参考`。

**输出模板**
【查询对象】 #X 机组｜本次启动

【事件ID】 SS-xxxx

【总消耗】
 - 水：xx.xx t
   - 煤：xx.xx t
   - 燃油：xx.xx t
   - 启机厂用电：xx.xx MWh
   
【分阶段明细】

 | 阶段 | 水(t) | 煤(t) | 油(t) | 厂用电(MWh) | 历史均值(油) | 差异率 |
 | ---- | ---- | ---- | ---- | ---- | ---- | ---- |

【结论】……

## A2：历史指定事件油耗明细
**问句示例**
- 历史上这次冷态启动的油耗是多少？
- 历史上这次 #2 机组热态启动的油耗是多少？

**处理逻辑**
1. 调用工具 `startStopStatic` 获取最新的一条启停记录 ，`startTime`参数和 `endTime` 参数不传
2. 调用工具 `startStopDetails`可以获取某一次启停记录详情 参数 `resultId` 取值为上一工具筛选出的结果的 `result_id`取值，可以获取关键阶段耗时
3. 调用工具 `getStartStopTotalMaterial`，参数`resultId`为筛选出来数据的 result_id 获取该次总燃油消耗量、关键阶段燃油消耗
4. 输出字段：启停工况类型、总燃油消耗量、关键阶段燃油消耗和关键阶段耗时统计；
   > 若部分阶段油耗字段采集缺失，则标注`无采集数据`，不做估算补全。

## A3：两次启停事件对比
**问句示例**
- 把这两次启动的耗时和物耗对比一下。
- #2 机组两次启动的耗时和物耗对比一下。

**处理逻辑**
1. 从上下文取两条事件 `result_id`（不足两条 → 兜底 F2）。
2. 分别调用 `startStopDetails` + `getStartStopTotalMaterial`。
3. 输出对比表：耗时(min)、水、煤、油、厂用电、各阶段油量，逐项计算差异率（保留 1 位小数）。
4. 定位差异突出阶段：差异率绝对值最大的阶段加粗标注。
5. 输出结论：差异显著项 + 可能影响因素提示（不做因果断言）。

**差异率公式**
`差异率 = (值B - 值A) / 值A × 100%`（值A 为 0 时标注“基准为 0，不计算差异率”）

## A4：单次启动阶段燃油拆解
**问句示例**
- 本次启动哪个阶段最耗油？

**处理逻辑**
1. 定位本次启动事件 `result_id`。
2. 调用 `getStartStopTotalMaterial` 取分阶段燃油明细。
3. 计算各阶段油量占比（保留 1 位小数），按油量降序排列。
4. 输出 TOP 阶段 + 占比 + 耗时，标注高耗油阶段与异常点提示。
5. 无阶段明细 → 兜底 F6。

## 公共约束
- 单位与精度严格遵循 `global-rules.md`；
- 数据缺失不得编造；
- 输出末尾可选追加交互指引（如需）。
