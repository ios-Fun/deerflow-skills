# 场景B：启停记录与统计

## 触发条件
关键词命中：启停了多少次、启停次数、停机时长、启停记录、启停列表、最近一次详情、冷/温/热态分类、非计划启停。

## 分支路由与优先级
> 优先级排序：B3（最近一次详情）> B4（N次列表）> B5（停机时长）> B2（分类统计）> B1（总次数）

| 分支 | 触发关键词 | 优先级 |
| ---- | ---- | ---- |
| B1 启停总次数统计 | 启停了多少次 / 累计启停次数 | 5 |
| B2 分状态分类统计 | 冷态/温态/热态 / 启动多少次停机多少次 | 4 |
| B3 最近一次启动详情 | 最近一次启动 / 最新启动时间 / 上次启动 | 1 |
| B4 最近N次记录列表 | 最近X次启停记录 / 启停明细 | 2 |
| B5 停机总时长统计 | 停机总时长 / 计划停机多久 / 故障停机 | 3 |

## 公共处理逻辑
1. 实体解析：`unitId`、`timeRange`、数值 N；未识别时间默认当年自然年；时间非法 → 兜底 F1。
2. 调用 `startStopStatic` 获取启停全流程关键业务字段。
3. 数据过滤：按 `data-filter-rules.md` 剔除试验/调试/脏数据。
4. 输出数据集质量元信息（内部判断，按需对外提示）。

## B1：启停总次数统计
**处理逻辑**
1. 实体解析：识别`nodeId` 取自全局前置规范匹配相似度最高返回结果中的 `id` 值 ，解析`timeRange`；未识别时间，默认取当年自然年；时间格式非法返回提示，不继续统计。
2. 调用工具 `startStopStatic` 可以获取到启动次数、停机次数和各种完成启停时间范围,通过启停时间范围需要自己计算出累计运行时长、累计停机时长并回答下列相关问题
3. 数据集过滤：执行公共前置过滤，剔除试验、调试、脏数据。
4. 指标统计：
    - 统计周期内**有效启动总次数**、**有效停机总次数**；
    - 计算机组累计运行时长、累计停机时长；
    - 计算启停事件闭环率：闭环事件数 / 全部生产事件数（用于数据质量提示）。
5. 事件索引构建：为过滤后每一笔启停事件生成业务索引ID，用于后续上下文下钻。
6. 周期边界校验：
    - 若周期结束时刻机组处于**运行未闭环**：停机事件未完成，不计入停机统计，输出边界说明；
    - 若周期结束时刻机组处于**停机未闭环**：本次停机时长仅统计至查询时刻，标注为“进行中停机”。
7. 数据质量校验：当事件闭环率＜80%，增加数据质量提示，告知用户部分事件未闭环，统计结果存在偏差。

**输出模板**

【统计范围】  
【统计对象】  
【数据口径】  
【启停统计】  
【周期累计指标】  
【边界说明】  

## B2：分状态分类统计
**处理逻辑**
1. 实体解析：识别机组、时间范围；执行公共数据过滤。
2. 调用工具 `startStopStatic` 可以获取到启动次数、停机次数、冷态/温态/热态
2. 基础总量输出：输出周期内启动总次数、停机总次数。
3. 启动事件分类统计（依据机组缸温/停机冷却时间判定的启动类型标签）：
    - 冷态启动、温态启动、热态启动分别计数，计算各类启动占全部启动事件的百分比，保留1位小数；
4. 标签完整性分支处理：
    - ✅全部事件带启动类型标签：输出完整分类统计；
    - ⚠️部分事件缺失标签：输出可统计部分，明确标注缺失标签事件数量；
    - ❌全部无标签：仅输出启动总次数，提示“暂无启动类型分类标签，无法做冷/温/热态拆分”。
5. 停机事件：默认不拆分；当用户明确追问停机原因分类（计划/非计划/故障/检修），追加停机分类统计。
6. 附加辅助指标：输出非计划启动次数（若数据源存在该标签）。

## B3：最近一次启动详情
**处理逻辑**
1. 实体解析：识别目标机组，时间默认取全量历史，支持用户限定时间范围。
2. 调用工具 `startStopStatic` 可以获取启停全流程关键业务字段
3. 过滤数据集，筛选启动类事件，按**启动开始时刻倒序**取第一条事件。
4. 调用工具 `startStopDetails`可以获取某一次启停记录详情 参数 `resultId` 取值为上一工具筛选出的结果的 `result_id`取值，若是筛选多个结果可以一次调用合并结果分析 ，这里面包含了此次启停的所有过程事件，根据返回结果具体分析
5. 调用工具 `getStartStopTotalMaterial` 可以获取启停物耗相关信息，`resultId` 参数为上一步工具返回结果 `result_id`
6. 提取启停全流程关键业务字段（换行展示）：
    - 启动开始时间：`YYYY‑MM‑DD HH:mm`  
    - 启动类型：冷态 / 温态 / 热态 / 未分类  
    - 锅炉点火时间、汽轮机冲转时间、机组并网时间  
    - 启动总耗时（点火至并网，单位min，整数）  
    - 机组带满负荷时间  
    - 启动最终状态：成功 / 异常中断 / 启动失败 / 启动进行中  
    - 事件ID、是否为非计划启动取值为 `result_id`  
    - 异常标记：存在异常则输出异常简述；无异常填“无”  
7. 实时状态判断：若事件为进行中，明确提示为中间快照，结果以事件闭环后为准。
8. 兜底：无匹配启动事件输出F3兜底话术。

## B4：最近N次记录列表
**处理逻辑**
1. 调用工具 `startStopStatic` 可以获取启停全流程关键业务字段
2. 调用工具 `getStartStopTotalMaterial` 可以获取启停物耗相关信息，`resultId` 参数为上一步工具返回结果 `result_id`
3. 公共过滤，全部启停事件按**事件完成时间倒序**，截取前N条；事件未完成的放在列表顶部并标记“进行中”。
4. 每条记录提取标准化字段：序号、事件ID、启停时间、启停类型、全过程耗时、物耗指标（启动燃油消耗、启机厂用电量）、事件性质（计划/非计划）、异常标记。
上下文支撑：每条记录携带事件ID，支持用户后续输入“查看第3次详情”、“查看事件SS‑xxxx详情”直接下钻，不需要重复输入机组。
6. 当有效事件小于请求N，输出实际条数，并提示“仅查询到X条有效启停事件”。

## B5：停机总时长统计
**处理逻辑**
1. 解析机组、时间范围，执行公共过滤。
2. 停机时长统计规则：
    - 闭环停机事件：停机开始时刻到停机结束时刻差值；
    - 进行中停机事件：停机开始时刻至查询当前时刻，单独标记，不参与占比计算；
3. 分类维度：计划停机、非计划停机、故障停机、检修停机；
4. 计算各类停机时长、占**闭环停机总时长**百分比（进行中停机不参与占比分母）；
5. 附加指标：非计划停机累计时长、非计划停机占比，供可靠性分析；
6. 数据提示：部分停机事件缺失停机原因标签时，输出“未分类停机”项，统计对应时长。

## 分支隔离
单轮只进入一个分支，命中多个取优先级最高。
