# 场景 D：启停过程分析与复盘

## 分支路由

| 分支 | 触发语义 | 优先级 |
| ---- | ---- | ---- |
| D1 启停过程优化建议 | 怎么优化 / 缩短 / 压缩空间 / 偏高归因 | 1 |
| D2 历史启停对比评价 | 最近N次对比 / 哪次最好 / 最容易拖时间 / 比历史高多少 / 重复问题 | 2 |
| D3 启停事件复盘 | 总结本次 / 复盘 / 还原时段 / 过程异常 | 3 |

> 同一问句命中多个分支时按优先级取最高。例如“最近3次哪一次最好、哪一次油耗偏高” → D2（评价优先于诊断）。

## D1：启停过程优化建议

### 子意图
| 子意图 | 触发问句示例 |
| ---- | ---- |
| D1-a 时间压缩空间 | #1机组冷态启动还可以怎么缩短时间？/ 哪个阶段最有压缩空间？/ 本次滑参数停机怎么优化？ |
| D1-b 物耗偏差归因 | 本次启动油耗偏高，主要高在哪个阶段？/ 本次启动除盐水消耗为什么比历史高？ |

### 处理逻辑
1. 实体解析：`unitId`；启动/停机类型由问句关键词判定。
2. 取数：
   - 调用 `startStopStatic` 取本事件 `result_id` 及历史同工况事件列表；
   - 调用 `startStopDetails`（`resultId`）取本事件阶段耗时与异常标记；
   - 调用 `getStartStopTotalMaterial`（`resultId`）取本事件分阶段物耗 + 历史均值。
3. **D1-a 时间压缩**：
   - 逐阶段对比：本事件阶段耗时 vs 历史同工况同阶段均值；
   - 计算可压缩量 = 本阶段耗时 − 历史均值（仅正值参与排名）；
   - 按可压缩量降序输出 TOP 阶段，标注每阶段压缩依据；
   - 结论句：可压缩空间集中在 X、Y 阶段，合计约 Z min。
4. **D1-b 物耗偏差归因**：
   - 逐阶段对比：本事件阶段油量/除盐水量 vs 历史均值；
   - 计算偏差率（保留 1 位小数），按偏差绝对值降序；
   - 输出 TOP 阶段 + 偏差值 + 偏差率，定位主要高耗阶段；
   - 结论句：本次偏高主要由 X 阶段贡献，偏差 xx.x%。
5. 无历史基线 → 兜底 F15（D1-a）或 F12（D1-b）。
6. 指出可优化阶段、关键参数和等待环节；建议需在规程允许范围内，不建议突破安全约束。输出末尾固定追加：`建议仅供参考，具体操作以运行规程为准。`

## D2：历史启停对比评价

### 子意图
| 子意图 | 触发问句示例 |
| ---- | ---- |
| D2-a 多事件报告 | 调取#1机组最近3次完整启停报告。 |
| D2-b 最优/最差评价 | 最近3次冷态启动哪一次最好？ |
| D2-c 阶段耗时聚合 | 最近几次启动最容易在哪个阶段拖时间？ |
| D2-d 物耗偏差量化 | 这次启动的物耗比历史平均高多少？ |
| D2-e 重复问题识别 | 本次启停有没有重复出现上次的问题？ |

### 处理逻辑（公共）
1. 实体解析：`unitId`、N（默认 3）、启动类型过滤条件（如“冷态启动”）。
2. 调用 `startStopStatic` 取最近 N 条符合条件的事件（按完成时间倒序）。
3. 逐事件调用 `startStopDetails` + `getStartStopTotalMaterial` 补充耗时与物耗。
4. 依据子意图分流输出。

### D2-a 多事件报告
- 每条事件输出一段结构化摘要：事件ID、启停类型、点火/冲转/并网时间、总耗时、油/水/厂用电、异常标记；
- 不输出完整明细表，突出对比项；
- 有效事件 < N → 兜底 F11。

### D2-b 最优/最差评价
- 评价维度显式列出：总耗时、点火至并网耗时、启动油量、启机厂用电；
- 每维度独立排名，输出该维度最优事件 ID；
- **不做综合加权评分**；
- 缺失维度不参与排名并标注；
- 全部维度缺失 → 兜底 F14。

### D2-c 阶段耗时聚合
- 跨 N 条事件，按阶段聚合耗时；
- 计算每阶段：平均耗时、最大耗时、超均值次数；
- 按“超均值次数 × 平均超幅”降序，输出最易拖时间的 TOP 3 阶段；
- 结论句：最近 N 次启动中，XX 阶段最易拖时间。

### D2-d 物耗偏差量化
- 以历史同工况均值为基准，计算本次各物耗项偏差绝对值与偏差率；
- 偏差率公式：`(本次 − 均值) / 均值 × 100%`，保留 1 位小数；
- 均值缺失 → 兜底 F12。

### D2-e 重复问题识别
- 取本事件与上一次同类型事件的异常标记字段；
- 求交集：两次均出现的异常 → 标记为“重复问题”；
- 输出：重复问题清单 + 出现次数 + 对应事件 ID；
- 无重复问题 → 输出“本次未发现与上次重复的异常项”；
- 异常字段为空 → 标注“无采集数据，无法比对”。

## D3：启停事件复盘

### 子意图
| 子意图 | 触发问句示例 |
| ---- | ---- |
| D3-a 全过程总结 | 帮我总结一下本次启动过程。 |
| D3-b 异常提取 | 本次停机过程中发生过哪些异常？ |
| D3-c 关键问题诊断 | 本次启机最值得复盘的问题是什么？ |
| D3-d 时段还原 | 帮我还原 14:00 到 16:00 这段启动过程。 |

### 处理逻辑（公共）
1. 定位本次事件 `result_id`（上下文复用）。
2. 调用 `startStopDetails`（`resultId`）取全流程事件序列与异常标记。
3. 调用 `getStartStopTotalMaterial`（`resultId`）取物耗用于总结补充。
4. 调用 `stageRecord`（`nodeId` + `eventName`）取阶段时间线。

### D3-a 全过程总结
- 输出：启停类型、关键节点时间轴（点火→冲转→并网→满负荷 或 解列→惰走→熄火）、总耗时、物耗概况、异常概况；
- 控制在 8~12 行内，不罗列全部明细。

### D3-b 异常提取
- 从 `startStopDetails` 的异常标记字段中逐条提取；
- 输出：异常发生时间、阶段、异常简述、是否闭环；
- 无异常 → 输出“本次启停过程未采集到异常事件”；
- 字段为空 → 标注“无采集数据”。

### D3-c 关键问题诊断
- 排序依据：异常严重度（高/中/低标签）> 偏离历史幅度；
- 取 TOP 1~3 输出，每条附数据依据；
- 无异常但有显著偏离 → 以“偏离项”形式输出；
- 均无 → 输出“本次启停过程未发现显著问题项”。

### D3-d 时段还原
- 解析起止时间，筛选 `startStopDetails` 中该时段内的事件；
- 按时间正序输出：时刻、阶段、事件、关键参数（若返回）；
- 时段内无事件 → 兜底 F13；
- **不做插值补全**，只输出已采集事件。

## 兜底
| 异常场景 | 文案编号 |
| ---- | ---- |
| 历史事件 < 2 条 | F11 |
| 无历史同工况均值 | F12 |
| 复盘时段无事件 | F13 |
| 评价维度全缺失 | F14 |
| 优化无基线 | F15 |
| 无法定位事件 | F2 |
| 工具异常 | F5 |

## 全局约束
1. 业务边界：只处理 D1/D2/D3 三个分支；不评估设备风险、不生成操作指令；
2. 分支隔离：单轮只进入一个分支；
3. 结论边界：只做相关性描述与数据对比，不做因果断言。
