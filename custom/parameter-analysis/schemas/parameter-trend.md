# 运行参数趋势图前端渲染协议

## 适用位置

用于 `parameter-analysis` Skill 的运行参数趋势分析结果。

当分析结果中存在可用于趋势展示的测点时，AI可输出该结构，由前端渲染参数趋势图。

## 输出要求

完成参数趋势分析后，如需要展示趋势图，必须输出以下固定结构，注意不要直接输出趋势数据：

```json
{
  "type": "parameter_trend",
  "title": "趋势图",
  "timeRange": {
    "start": "2026-08-13 13:00:00",
    "end": "2026-08-13 14:00:00"
  },
  "series": [
    {
      "tagName": "凝结水泵A轴承温度",
      "unit": "℃"
    }
  ]
}
```
