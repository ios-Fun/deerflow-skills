# 模拟量状态分析

## 适用场景
- 判断参数是否正常、偏高、偏低
- 查询设备运行状态
- 查询参数的严重度、异常数量

## 查询工具
优先使用 `get_tag_statistic_data`。

### 返回数据含义
| 字段 | 含义 | 用途 |
|------|------|------|
| 实际值 | 测点当前运行值 | 判断参数当前水平 |
| 估计值 | 基于历史数据或模型的估计值 | 与实际值对比，判断偏差程度 |
| 严重度 | 异常程度分级 | 判断是否异常及异常等级 |
| 异常数量 | 统计周期内异常次数 | 判断异常频率 |

## 分析逻辑
实际值 → 统计状态 → 严重度/异常程度 → 当前参数状态

1. 以 `get_tag_statistic_data` 返回的统计结果为主要判断依据。
2. 不得仅因实际值数值较大或较小，就自行认定超限或异常。
3. 统计数据已明确反映异常状态时，直接使用统计结果判断，无需再通过其他测点验证。
4. 用户未询问数据质量时，不得默认怀疑数据失真或测点故障。

## 注意事项
- 涉及"持续、升高、下降、异常"等趋势判断时，不能只看单点统计，需结合 `get_tag_values` 查询时序数据。
- 没有明确阈值时，只能根据历史趋势和相关数据判断"明显偏高/偏低"等相对状态，不得直接认定为超限。
