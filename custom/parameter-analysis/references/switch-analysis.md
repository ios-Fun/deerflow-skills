# 开关量状态分析

## 适用场景
- 查询设备/线路的分闸、断开状态
- 查询开关动作发生时间
- 查询某时间段内开关跳变情况
- 查询保护动作、跳闸、断线告警等

## 查询工具
优先使用 `get_last_time_by_switch_name`。

### 参数传递规则
| 场景 | 传递参数 | 返回结果 |
|------|---------|---------|
| 查询开关量最后一次等于某值的时间 | 仅传 `value` | 该开关量等于该值的最新时间 |
| 查询某时间段内开关量跳变情况 | 传 `startTime` 和 `endTime` | 该时间段内每次变动的时间戳（如 1→0 或 0→1） |

## 分析逻辑
1. 根据返回结果直接判断开关状态或跳变时间。
2. 能直接回答用户问题时，不做引申。
3. 返回结果无法回答时，向用户询问更多信息（如具体时间范围、期望的状态值等）。

## 注意事项
- 开关量查询不使用 `get_tag_statistic_data`，该工具仅适用于模拟量。
- 如查询集电线路分闸状态，需先通过 `get_tags_of_instance` 获取线路下的开关量测点，再查询各测点状态。
- 多个开关量需要汇总时，先分别查询，再按线路/设备维度聚合结果。
