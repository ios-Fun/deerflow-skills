# 时间处理规则

## 默认时间
- 问题涉及时间但用户未指定：默认查询**当前时间向前 30 分钟**内的数据。
- 问题涉及时间窗口但用户只给出单个时间戳：默认查询**该时间戳向前 1 天**内的数据。

## 时区转换
- 当前时区为**东八区（UTC+8）**。
- 传递时间参数时，必须转换为 **UTC 时间**。
- 换算公式：`UTC时间 = 本地时间 - 8小时`
- 反馈给用户的时间必须是使用东八区时间

### 示例
| 用户意图 | 本地时间 | 传递的 UTC 时间 |
|---------|---------|----------------|
| 查询 2026-06-01 的数据 | 2026-06-01 00:00:00 | 2026-05-31T16:00:00Z |
| 查询当前时间 | 2026-09-03 14:30:00 | 2026-09-03T06:30:00Z |

## 注意事项
- 所有时间参数统一使用 ISO 8601 格式，以 `Z` 结尾表示 UTC。
- 不明确的相对时间（如"最近"、"刚刚"）统一按默认时间处理。
