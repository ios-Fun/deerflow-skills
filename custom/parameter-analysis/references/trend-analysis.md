# 趋势变化分析

## 适用场景
- 查询参数何时开始升高/下降
- 判断参数是否持续变化
- 分析参数变化趋势

## 查询工具
使用 `get_tag_values` 获取时间序列数据。

## 分析逻辑
初始水平 → 中间变化 → 当前水平

1. 确定查询时间范围（遵循时间处理规则）。
2. 根据时间序列识别变化起点、变化速率、当前状态。
3. 结合其他相关参数（如负荷、温度等）判断变化是否合理。

## 输出要求
- 用户要求查看趋势或分析基于时间范围数据时，**必须**输出 `parameter_trend` 趋势图结构。
- 趋势图协议见 `schemas/parameter-trend.md`。
- 多个相关参数对比时，优先合并为同一个趋势图。

## 注意事项
- 趋势图数据必须来自 `get_tag_values` 实际查询结果，不得编造。
- 数据间隔根据时间范围自动选择：短时间范围用小间隔，长时间范围用大间隔。
