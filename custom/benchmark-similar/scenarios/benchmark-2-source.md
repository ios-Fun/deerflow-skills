# 标杆选择逻辑

## 匹配问题
- 这个标杆是怎么选出来的？
- 标杆来源是什么？
- 为什么选这个标杆？
- 标杆怎么来的？
- 这个标杆依据是什么？
- 标杆是怎么定的？

## 处理逻辑
1. 判断是否为追问：
   - 若上下文存在上一轮 `getBenchmarkByTagCode` 返回的 `evaluationId`，直接调用 `getRangeValue`。
   - 若上下文不存在 `evaluationId`，先调用 `getBenchmarkByTagCode` 获取当前指标标杆及 `evaluationId`，再调用 `getRangeValue`。
2. 调用 `getRangeValue`，获取：
   - 当前工况实际值
   - 最终标杆值
   - 候选样本实际值、标杆值、偏差值（如有）
3. 按输出模板展示。

## 输出模板
| 工况名称 | 实际值 | 标杆值 | 偏差值 |
|---|---:|---:|---:|
| 当前工况 | ... | ... | ... |
| 最终标杆 | ... | ... | 0 |
| 候选样本1 | ... | ... | ... |
| 候选样本2 | ... | ... | ... |
| 候选样本3 | ... | ... | ... |

说明：
- 偏差值 = 实际值 - 标杆值。
- 对煤耗、厂用电率等越低越好的指标，正偏差表示偏劣；对效率等越高越好的指标，负偏差表示偏劣。
- 若系统只返回最终标杆，则只展示“当前工况”和“最终标杆”两行。
- 若候选样本明细不可用，不虚构候选样本。

## 异常处理
- 若无法获取 `evaluationId`，只说明通用标杆选择逻辑，不猜测系统实际参数。
- 若 `getRangeValue` 调用失败，回复：
  “无法获取标杆候选样本明细，请稍后重试。”
- 不得用历史数据或示例数据代替当前结果。
