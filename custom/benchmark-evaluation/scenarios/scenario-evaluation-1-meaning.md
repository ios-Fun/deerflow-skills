# 评估单含义解析

## 匹配问题
- 这个寻优评估单是什么意思？
- 这张单子解释一下。



## 处理逻辑
1. 调用 `getEvaluationByTagCode`，传参`tagCode`、`startDate`、`endDate`传指定时间前后一个小时的时间,指标编码获取寻优单数据。
2. 先用一句运行人员易懂的话说明当前哪个指标没有达到同工况较优水平。
3. 解释核心字段：【触发对象】【实际值】【标杆值】【偏差】【关联因素】【预计影响】。
4. 最后给出可执行的下一步入口。

【标杆值】...
