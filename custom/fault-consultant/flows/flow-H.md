# H类：诊断单解释

## 前置条件
- 已获取诊断单上下文

## 执行步骤

1. **用一句话直白解释**
   - "系统认为设备可能存在什么问题"
   - 使用运行人员能理解的语言

2. **解释触发该诊断的关键预警与变化规律**
   - 哪些参数发生了变化
   - 变化规律如何

3. **说明严重程度与建议动作**
   - 当前风险等级
   - 建议操作

4. **必要时调用 `unit_graph_show`**
   - 获取故障模式推导图辅助解释

## 输出格式

### 结论
- 一句话解释诊断单含义

### 证据
- 触发该诊断的关键预警
- 变化规律

### 分级与风险
- 严重程度

### 建议动作
- 建议操作

### 边界说明
- 数据支持范围
