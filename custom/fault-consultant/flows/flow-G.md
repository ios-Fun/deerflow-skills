# G类：故障模式知识（无需诊断单）

## 前置条件
- **不需要诊断单**
- 直接执行本流程

## 执行步骤

### 分支1：查询某设备下的故障模式

1. 调用 `match_for_best` 匹配设备
2. 使用返回的名称字段 `name` 作为参数 `device_name` 调用 `default_graph_detail` 查询设备下故障模式信息
3. 直接反馈给用户，不执行后续流程

### 分支2：未能匹配到设备

1. 调用 `ask_clarification` 向用户索要更全面的信息
2. 直接反馈给用户，不执行后续流程

### 分支3：查询某测点可能触发的故障模式

1. 调用 `default_graph_detail`（参数仅使用 `tag_list`，传入测点id）
2. 列出该测点可能触发的故障模式

## 输出内容

1. **列出设备已配置/已启用的故障模式**
   - **不要**扩展成未配置的百科式故障大全

2. **每个模式用一句话说明典型特征**

3. **触发条件**
   - 用业务可读方式展示关键特征条件
   - 预警项、关联参数变化、时间/组合关系

4. **为什么没匹配某模式**（如用户询问）
   - 逐项对照【已满足 / 未满足 / 数据缺失】
   - 说明因此未触发

## 输出格式

### 结论
- 直接回答：该设备有哪些故障模式

### 证据
- 故障模式列表及触发条件

### 边界说明
- 仅列出系统已配置的模式
