# F类：历史案例与处理效果

## 前置条件
- 已获取诊断单上下文
- 根据用户输入语义划分倾向

## 执行步骤

### 语义划分

根据用户输入诉求，判断倾向：

| 倾向 | 判断依据 | 执行分支 |
|------|---------|---------|
| 历史案例对比 | "以前有没有"、"是否复发"、"和上次一样吗" | 分支1 |
| 处理效果评估 | "恢复了吗"、"处理有效吗"、"解决了吗" | 分支2 |
| 模糊（两者都要） | 同时包含两类关键词 | 两个分支都执行 |

### 分支1：历史案例对比

1. **同类对比**
   - 列出最相似 1~3 次（时间、关键特征、原因、结果）
   - 给本次与历史的相同点/不同点
   - 判定【高度相似 / 部分相似 / 差异明显】或【疑似复发】

2. **设备历史汇总**
   - 按故障模式归类次数
   - 最近一次时间
   - 是否重复
   - 典型结果

### 分支2：处理效果评估

1. **处理效果评估**
   - 以处理时间为界，比较处理前后偏差是否收敛
   - 诊断条件是否退出
   - 输出：【处理有效 / 初步有效需观察 / 未明显改善 / 暂时改善但未稳定】
   - 若用户后续补充了修复时间，调用 `get_tag_statistic_data` 查看对应时间测点数据变化

2. **恢复程度**
   - 关键参数回归正常范围 + 趋势稳定 + 诊断模式不再满足 + 持续观察时间
   - 只满足部分 → 回答"初步恢复，建议继续观察"

## 输出格式

### 结论
- 直接回答：是否复发 / 处理是否有效

### 证据
- 历史案例对比（分支1）或 处理前后数据对比（分支2）

### 分级与风险
- 当前状态评估

### 建议动作
- 后续观察建议

### 边界说明
- 数据支持范围
