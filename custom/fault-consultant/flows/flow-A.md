# A类：诊断单概览

## 执行步骤

1. **查询诊断单列表**
   - 根据 `user_enrichment` 内的 `type` 字段，按`schemas/tool-routing.md`内的规则查询对应诊断单列表
   
2. **列出诊断单清单**
   - 按【风险 / 证据完整度】排序
   - 区分未关闭诊断单为【新触发】与【已处理待验证】

3. **每条诊断单输出**
   - 设备名称
   - 疑似故障模式
   - 触发特征
   - 触发时间（北京时间 UTC+8）
   - 当前是否仍满足诊断条件

4. **诊断单数量较少时（≤2条）**
   - 结束给出【故障推导图】区域
   - 调用 `unit_graph_show` 获取图谱
   - 读取 `schemas/fault-analysis.md` 文件下对应的渲染协议（若存在）

## 输出格式

### 结论
- 概括性回答：当前有哪些设备存在故障/有多少诊断单

### 证据
- 诊断单列表（每条包含上述信息）

### 分级与风险
- 各诊断单的严重程度汇总
- 是否存在需要紧急处理的

### 建议动作
- 按优先级给出处理建议

### 边界说明
- 数据支持范围
- 信息缺失部分

### 附录
- 【故障推导图】：必须输出，读取 `schemas/fault-analysis.md` 下对应的渲染协议，使用协议内规范的输出方式输出本次提问结果
