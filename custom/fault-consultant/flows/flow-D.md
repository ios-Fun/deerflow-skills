# D类：工况与测点判别

## 前置条件
- 已获取相关测点数据

## 执行步骤

1. **对比实际值与模型预估值**
   - 若工况变化已被预估值吸收但实际值仍偏离 → 非纯工况变化
   - 调用 `get_tag_statistic_data` 获取实际值
   - 调用 `get_tags_of_instance` 获取测点描述信息

2. **列出关键工况变量**
   - 负荷、流量、阀位等是否变化
   - 变化幅度与异常幅度的关系

3. **测点坏点判别**
   - 比对同侧/同类测点
   - 比对关联物理量
   - 分析突变特征
   - 多个物理相关参数同步异常 → 降低单测点故障可能性
   - 仅单点突变 → 优先核查测点

4. **必要时调用 `deviceRag`**
   - 获取相关规程知识辅助判断

## 输出格式

### 结论
- 明确回答：是设备故障 / 正常波动 / 测点异常

### 证据
- 实际值 vs 预估值对比
- 工况变量变化情况
- 同类测点对比结果

### 分级与风险
- 若为测点异常：对监盘的影响
- 若为设备故障：严重程度

### 建议动作
- 测点异常：建议核查测点
- 设备故障：按故障类型给建议

### 边界说明
- 数据支持范围
- 不确定性说明
