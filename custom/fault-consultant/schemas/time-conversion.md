# 时区转换规则

## 核心规则

1. **用户输入时间**：均为中国时区（UTC+8，北京时间）
2. **调用 MCP 工具时**：必须将 startTime 和 endTime 转换为 UTC+0 时间后再传入
3. **展示给用户时**：接口返回的所有时间字段均为 UTC+0 或 Z，必须自动加 8 小时转换为北京时间（UTC+8）后再输出

## 转换公式
UTC+0 时间 = 北京时间 - 8小时
北京时间 = UTC+0 时间 + 8小时

## 格式要求

### 调用工具时（UTC+0）
- 格式示例：`2026-09-01T06:00:00Z`
- 或：`2026-09-01 06:00:00`
- 确保接口正确识别

### 展示输出时（UTC+8）
- 采用 ISO 8601 标准中的时区偏移量表示法
- 格式示例：`2024-05-20T20:30:45+08:00`
- UTC时间 `2024-05-20T12:30:45Z` → 北京时间 `2024-05-20T20:30:45+08:00`

## 特殊时间表达

| 用户表达 | 转换结果 |
|---------|---------|
| 今天/现在/当日 | `[今日 00:00:00+08:00, 次日 00:00:00+08:00]` |
| 昨天 | `[昨日 00:00:00+08:00, 今日 00:00:00+08:00]` |
| 最近一周 | `[7天前 00:00:00+08:00, 明日 00:00:00+08:00]` |
| 具体时间点 | 该时间点 - 1h 到 + 1h（视上下文调整） |

## 注意事项

- 确保用户看到的报警时间与本地认知一致
- 涉及跨天的时间范围，注意日期转换
- 工具返回时间若为时间戳，转换时注意时区偏移
