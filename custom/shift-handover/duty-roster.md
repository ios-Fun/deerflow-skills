# 值班规则

## 1. 规则用途

用于定义电厂运行值班的班次、时间、班组轮换及值次边界。值班规则支持按实际电厂运行制度进行配。

---

## 2. 默认值班模式

```yaml
shift_mode: "自定义"
timezone: "Asia/Shanghai"
shifts:
  - name: "早班"
    start: "08:00"
    end: "16:00"
  - name: "中班"
    start: "16:00"
    end: "00:00"
  - name: "夜班"
    start: "00:00"
    end: "08:00"
```
注：
- 早班：08:00~16:00  (5月20日早班)
- 中班：16:00~00:00  (5月20日中班)
- 夜班：00:00~08:00  (5月21日夜班)
