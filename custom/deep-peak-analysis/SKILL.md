# 核心规则

## 负荷指标统计数据获取

- 查询将用户原语句传入`match_for_best`工具进行查询，若查未出type为机组的信息。
- 根据查询到的机组，若没有查到，则将参数unitId设置为null和负荷率阈值（0.5）调用深度调峰统计接口`get_deep_peak_statistic`获取统计
- 禁止查询其他负荷率阈值

## 负荷指标数据获取

若根据前方返回数据中的存在指标id值（indicatorId），则直接使用，若没有结合参数（matchString=负荷率，num=10）调用`match_for_best`工具获取负荷率相关指标
- 根据获取到的负荷率相关指标id调用`get_tag_values`接口（返回的单位是%）获取实际数据
注意：
- 若未查到相关指标或者查到的相关指标没有查询到相关数据，直接返回用户系统内暂无法分析
- 用户未指定时间范围时,查询最近7天时间内的

## 深度调峰判定

根据"负荷指标统计数据"返回的result是否有时间段数据来判断是否进入深度调峰。
* 若result为空，接借助于"负荷指标数据"中结合用户明确指定的阈值，例如“0.3”，来判断深度调峰。
* 若负荷指标数据为空，直接返回无法根据已有数据判断，禁止额外调取其他工具。

### 运行时间统计
关注"负荷指标统计数据获取"返回的：
* 总运行时间（totalDuration）
* 运行次数result的数组长度
* 单次最长持续时间
* 单次最短持续时间
对于“运行时间多久”类问题，优先直接使用统计接口，避免获取大量原始负荷数据。

### 4. 最低负荷

当用户询问“深度调峰期间最低负荷”时，根据"负荷指标统计数据获取"返回result分析：
1. 获取深度调峰运行区间；
2. 获取区间内负荷统计结果；
4. 给出对应负荷率与最低负荷（minValue）出现时间（minValueTime）。

## 输出要求

- 回答应直接给出统计结果，如果需要展示负荷率趋势，请输出 ECharts/Mermaid 的配置代码。
- 如果统计结果无法判断，应明确说明缺少的数据或判定依据，不得自行推测。
