# 经济性拖累系统分析

## 匹配问题
- 最近经济性变差主要是哪个系统拖累的？
- 经济性变差主要来源是哪个系统？
    
## 处理逻辑
1. 调用`getEvaluationLastAll`工具，获取所有系统经济性对标任务的最新的寻优結果。
2. 给出各系统主要偏差指标和贡献排序。
3. 若系统没有可量化贡献算法，则用“偏差程度排序”替代，不虚构贡献值。

## 输出模板

【经济性总体判断】...

【各系统偏差与排序】

| 系统 | 主要偏差指标 | 偏差程度 | 排序 |
|---|---|---|---|
| 锅炉 | ... | ... | ... |
| 汽机 | ... | ... | ... |
| 厂用电 | ... | ... | ... |

【主要拖累系统】
- ...（说明依据）

【说明】
- 若无可量化贡献算法，以上为偏差程度排序，不代表量化贡献值。

## 异常处理
- 若系统未接入某层级数据，明确标注“当前无数据支撑”。
- 不得虚构贡献值或贡献比例。
