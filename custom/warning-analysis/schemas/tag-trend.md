# 测点趋势图前端渲染协议

## 适用位置

用于 `warning-analysis` Skill 的测点趋势分析结果。

当分析结果中存在可用于趋势展示的测点时，可输出该结构，由前端渲染参数趋势图。

## 输出要求

完成参数趋势分析后，如需要展示趋势图，必须输出以下固定结构，禁止增删改任何参数，禁止直接输出趋势数据：

```json
{
  "type": "tag_trend",
  "title": "趋势图",
  "timeRange": {
    "start": "2026-08-13 13:00:00",
    "end": "2026-08-13 14:00:00"
  },
  "series": [
    {
      "tagId": 0,
      "unit": "℃"
    }
  ]
}
```
