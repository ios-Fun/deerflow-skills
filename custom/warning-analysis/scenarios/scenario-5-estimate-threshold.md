# 场景5：预估值和动态阈值问题、发展趋势

## 适用问题

- 为什么触发预警？
- 为什么没有达到 DCS 报警值却预警？
- 实际值还是工况变化？
- 预估值为什么变化？
- 参数偏差是否异常？
- 发展趋势判断

## 允许工具

- `search_tags`
- `get_tag_statistic_data`
- `get_tag_values`
- `get_alarm_list`（若需要获取 tagIds，但已有 alarmList 可跳过）

## 执行步骤

1. 若尚无 `alarmList`，先调用 `get_alarm_list` 获取有效预警涉及的测点ID，存入 `tagIds`。
2. 对 `tagIds` 中的测点ID并发调用 `search_tags` 查询测点信息（返回本系统的测点信息配置）。
3. 对 `tagIds` 中的测点ID并发调用 `get_tag_statistic_data` 查询指定时间范围内的预测点趋势统计。
4. 对涉及的测点ID调用 `get_tag_values` 查询测点具体趋势。
   - 返回：时间 `date`、实际值 `RealTimeData`、估计值 `Estimate`、严重度 `TagSeverity`。

## 分析要求

- 用一句话先说明触发原因，需要分析：
  1. 确定测点信息返回内容
  2. 涉及到的测点报警值
  3. 动态阈值带（测点信息中的正偏差阈值、负偏差阈值、高报、高高报、低报、低低报，其中 [估计值-负偏差阈值, 估计值+正偏差阈值] 为动态阈值带）
  4. 严重度层级（高高报严重度、高报严重度、低报严重度、低低报严重度）
  5. 测点数据变化趋势
- 趋势分类：
  - **扩大**：实际值与模型预估值之间的偏差持续增加
  - **稳定**：偏差在一定范围内波动，没有明显扩大或恢复
  - **恢复**：偏差持续缩小，并重新接近模型预估值
  - **波动**：偏差反复扩大和缩小，暂时无法判断明确发展方向

## 输出要求

- **触发报警问题**：
  - 回答：**本次预警不是因为超过 DCS 固定报警值，而是因为当前实际值相对于当前工况下的模型预估值出现偏离。以`智能监盘`系统的模型算法作为依据来解释**
  - 同时给出分析：测点信息、实际值、预估值、预警持续时间、预警类型。
  - 说明属于“实际值变化报警”还是“工况变化报警”。
- **预估值变化问题**：
  - 直接参考实际值与估计值趋势分析，回答预估值会随负荷、流量、温度、阀位等关联工况变化而动态调整，不必额外分析工况关联（除非用户同时询问模型参数）。
- 必须展示趋势图（调用了 `get_tag_values`）。
