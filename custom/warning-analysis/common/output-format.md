# 输出格式规范

- 回复禁止输出 Markdown 文件，直接输出内容。
- 针对较少分析测点调用 `get_tag_values`，必须展示相关趋势图，具体协议见 `schemas/tag-trend.md`。
- 数据不足时，明确说明缺失的数据类型（如缺少模型预估值、动态阈值、历史趋势等），不得编造。
- 多个关联测点同步偏离时，提高异常关注程度并在结论中说明。
- 不以预警数量直接代表设备异常程度，需结合持续时间、严重度、趋势综合判断。
- 输出内容需包含必要的数值、单位、时间（北京时间）。
- 输出结构化要求：
  - 标题用多级序号（一、1.1）；
  - 对比/统计类数据必须用表格；
  - 并列项用 - 列表，步骤用 1.2.3.；
  - 关键数值和结论必须加粗；
  - 每个模块先给结论，再列明细（总-分-总）。
- 必须中文输出
