When a query is parked pending the agent's clarifying questions (e.g., 机组 #1/#2 与 口径 confirmation for the '最近一次启停' query), the user does not answer the clarification menu; they later return with a fresh self-contained query that embeds the requested disambiguation (e.g., '最近一次#2启动是什么时候'), resolving the pending item on their own terms.
